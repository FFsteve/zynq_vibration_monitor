| 顶层 | ModelSim检查数 | XSim检查数 | 错误数 |

选择器覆盖全部262144个signed18输入，三轴分别遍历全范围；每个原始/滤波事件、错拍、无效保持、SEQ及复位后极值都符合参考。线缆还原误差严格在0～3计数，不截低16位、不回绕；非法模式-1/2在两个仿真器均主动拒绝。

系统两模式各输入4096个主合成样本，再加仅X、仅Y、仅Z各512个样本，总5632包、40个完整特征窗口。每模式逐字段对照18位内部结果、十字节回传、窗口MS/RMS/峰值、首末SEQ、ID和报警。正常负载无输出丢弃，三轴无串扰，多次SEQ回绕正常。

主通道 `CLK_HZ=1152000, BAUD=115200`，每位10拍，正常连续事件**严格4608拍/样本**，名义250包/s。相对50MHz参数为约43.4倍时间压缩，不能称作实测250Hz。独立默认参数顶层使用真实50MHz/115200、434拍位宽和200000拍样本周期，原始/滤波/ACK三通道分别覆盖正常、坏校验和恢复。

### 异常、拥塞及全状态恢复

- 错误包头、坏校验、停止位错误、九处截断、字节超时、SEQ重复/跳号和断流后恢复；错误不产生原子样本，缺口后重新预热再建完整窗口，报警有效性正确失效。
- 输出暂停期间保持256个输入样本：在途1包加等待4包被接纳，其余251包明确丢新包；队列顺序和诊断守恒，滤波不丢样，窗口仍完成且报警可更新。撤暂停后五个已接纳包按序排空。
- 字节中途请求暂停仍完成当前8N1字节，后续字节只握手一次；没有冻结半个位或重复发送。板级暂停固定0，不把此测试接口当作真实UART流控。
- 有在途包和四包等待积压时复位，清除接收/队列/当前发送及诊断；滤波运算中复位取消旧结果。恢复后首样本重新建立基线、零历史，最终200包常量输入得到零振动特征及window_id=0，没有旧统计泄漏。
- 既有队列满时同拍出入和解析器超时边界由原模块自检再次实际回归。第七阶段仍需执行所有阶段的完整回归，本轮不冒充已经冻结交付版本。

## 实际RTL量化结果

两工具各导出两套56320字节串口记录、5632组18位内部三轴、40组窗口特征和完整时间戳。独立Python逐项一致；量化直接使用核对后的实际RTL观测，未将数值期望回填成仿真数据。

合成主序列使用250Hz假设，在样本索引1000～3999的3000项上作正弦/余弦加常数的最小二乘拟合，剔除启动瞬态。三轴输入幅值分别10000/9000/6000计数。

| 轴与频率 | 完整18位内部增益 | 线缆解码乘4后的增益 |
|---|---:|---:|
| X，10Hz | +0.083199dB | +0.083349dB |
| Y，30Hz | +0.153248dB | +0.152836dB |
| Z，60Hz | -61.650538dB | -61.783342dB |

两种回传模式下内部计算结果相同；线缆量化没有影响内部RMS/报警。上述仅验证这些合成频率，完整频响还可查第四阶段报告，不替代真实传感器激励、校准或实际采样验收。

实际CSV/JSON和二进制证据归档于 `report/evidence/stage6/`，量化表为 [CSV](stage6_quantification.csv)。两仿真器同类导出哈希一致；完整路径和哈希在JSON中记录。离线记录换算工具还实际测试了原始/滤波显式尺度及拒绝覆盖旧证据，`physical_test_pass`保持null，不自动判板测通过。

### 处理与线缆时间

以解析器raw_valid发布沿为起点，空队列且未暂停时：

| 项目 | 实际结果 |
|---|---|
| 原始模式TX首起始位 | 4拍，50MHz下80ns |
| 滤波模式TX首起始位 | 198拍，50MHz下3.96us |
| 窗口末项对应的对齐特征 | 218拍，50MHz下4.36us |
| 默认十字节整包线缆时间 | 43400拍，868us；包内字节无额外间隙 |
| 默认正常包起点间隔 | 200000拍，4ms；坏包不回传，跨坏包的合法回包起点相隔400000拍 |

首位延迟不包含输入包在接收线上的发送时间，也不是FIR信号的124ms群延迟。整包线缆时间由独立解码观测的字节起始时间及完整8N1位宽核对，不能把最后停止位中心当成整个停止位结束。

## 两模式完整板级实现

两次均从源码独立完成综合、优化、布局和布线，复用原三端口物理约束并使用新层次专用CDC约束。实际原理图页与既有引脚文档已重新核对；不新增引脚、不修改原约束。

| 项目 | 原始模式 | 滤波模式 |
|---|---:|---:|
| LUT | 3401，19.32% | 3324，18.89% |
| 触发器 | 6101，17.33% | 6091，17.30% |
| DSP / BRAM / 锁存 | 6 / 0 / 0 | 6 / 0 / 0 |
| 50MHz内部建立裕量 | 5.205ns | 8.300ns |
| 内部保持裕量 | 0.037ns | 0.028ns |
| 未约束内部端点 | 0 | 0 |

两个模式均实际检查三轴FIR、三个开方器及报警存在；旧未连接发送器被移除，只剩 `u_core/u_tx` 驱动外部回传。427位调试快照的实际开销已计入，不把仅剩通信的优化网表冒充完整系统资源。

CDC报告为一项CDC-3 Info，深度2且ASYNC_REG生效；仅切断异步输入到第一级D，第二级同步路径仍受约束并输出单独报告。异步串口输入/输出各有一个无同步IO延迟的端口提示，未虚构外部采样时钟或0ns预算。

DRC两模式各保留8项Warning：3条DPOP-1、3条DPOP-2、1条RTSTAT-10、1条ZPS7-1，无Error/Critical Warning。DSP提示是流水优化建议；RTSTAT涉及保留调试寄存器的未接出网络；ZPS7-1留待最终配置评估，没有屏蔽或擅自引入PS。该实现结果不等于比特流/板卡验收通过。

## 本次纠错与证据边界

1. 新包装层最初继承了子模块的output reg声明，Verilog不允许模块驱动reg连接；改成output wire后重跑，未修改旧模块。
2. 主激励最初相差一拍，通过增加严格4608拍周期检查纠正；不能用“约250包/s”掩盖计数边界。
3. 原始模式最初仅标记调试网络，优化阶段移除了无真实负载的计算支路。检查主动失败；追加网络DONT_TOUCH仍不足，实际网表确认只是跨层网络被标记。最终改为427位明确保留的调试快照寄存器，支路保留检查与完整实现均重新通过。首次261LUT/371FF/0DSP的失败网表证据保留于 `build/stage6_removed_branch_evidence/`，没有放宽检查。

第六阶段的软件与实现部分已完成。实物记录、传感器初始化/校准、真实采样稳定性和真实报警门槛仍未验收；按此前约定最终阶段统一上板。第七阶段需要全部自检、失败案例回归、最终源码重建、版本冻结以及干净启动的实际演示证据。
