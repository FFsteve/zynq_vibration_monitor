# 第四阶段：三轴去直流与定点 FIR 设计

设计日期：2026-10-30；实现更新：2026-10-31。状态：**具体方案已获用户批准，四个RTL及配套自检已实现，双仿真器和隔离内部时序检查结果见实现验证报告。**

用户接受第三阶段已验证的基本通信成果，允许将 MPU6050 静态偏差后续处理，并授权开始第四阶段；随后确认先按 250 Hz 采样、保留约 5～30 Hz、抑制 50 Hz 及以上设计。原始量值、初始化回读、长期时序和边界停止位提示继续保留为未关闭事项，不将暂缓排查写成校准通过。

项目 `AGENTS.md` 要求：先解释输入输出、寄存器、状态机、周期和验收标准，编写较大规模新 RTL 前等待用户批准。2026-10-31用户明确授权继续编写未完成内容并要求每阶段自动运行仿真，已据此实现本文的RTL与Testbench。

## 范围与数据路径

三轴分别处理，避免只选 Z 轴而丢失方向信息。每轴使用同一组系数、独立的直流状态和历史数据：

```text
合法包的 SEQ、X/Y/Z
    -> 事件接纳、序号/断流检查
    -> 三轴直流估计及相减
    -> 三轴 63 抽头串行乘加 FIR
    -> 18 位三轴结果、原 SEQ、输出有效及历史完整标志
```

第四阶段先交付独立计算模块及可测试适配层。现有 `top`、`monitor_core`、原始十字节 UART 回传和 STM32 程序保持当前行为；新增 `filter_monitor_core` 复用现有通信核心，并把合法三轴并接给滤波链，供集成仿真及后续特征模块使用。适配层导出计算结果作内部接口，不为它们新增板级引脚。

暂不把 18 位结果截成 16 位塞进原始包，也不额外增加第二包。十字节输入布局和原始回传语义均不改变；未来需要传输滤波结果时，另行确认输出表示、饱和和 PC 区分方式。当前版本下载到板上的设计因此不会自动获得 FIR，第四阶段主要靠仿真与隔离综合验收。

不引入 PS、AXI、Linux、PYNQ、FFT 或 FIR IP。窗口均方值、峰值和报警留给后续阶段。去直流消除近似恒定分量，不修复比例误差、机械安装、动态重力、饱和或采样不均匀；不写入约 5288 的临时传感器校准值。

## 频率目标与数值选择

| 项目 | 设计值／验收要求 |
|---|---|
| 名义采样率 | 250 Hz；每个被接纳的合法样本推进一次状态，不能按 50 MHz 推进滤波历史 |
| 直流处理 | 一阶基线估计，更新比例 1/32；初次样本直接建立基线 |
| FIR | 63 抽头，Hamming 窗低通，设计频率 40 Hz |
| 通带验收 | 整体 5～30 Hz 增益在 -0.25～+0.25 dB |
| 阻带验收 | 量化系数的小信号线性模型在 50～125 Hz 不高于 -55 dB |
| 整数模型正弦检查 | 幅度 10000 计数时，50/60/80/100 Hz 不高于 -50 dB，单独记录舍入噪声 |
| 暂不承诺的指标 | 低于 5 Hz 的严格阻带、实物频响、传感器前端抗混叠或工业故障识别 |

这里的 5 Hz 是通带验收下限，不是陡峭高通截止点；40 Hz 是窗函数低通设计频率，接近约 -6 dB 点，不是通带边界。若后续要求严格 5～30 Hz 带通，应重新确定低频阻带与过渡带，不能只改名称。

直流基线的理想更新为 `b[n]=b[n-1]+(x[n]-b[n-1])/32`，输出使用更新前的误差 `d[n]=x[n]-b[n-1]`。其线性频响为 `(1-z^-1)/(1-(31/32)z^-1)`；初次样本的基线装载是特殊初始化，不按稳态线性系统解释。常量初始偏置可立即输出零；后续阶跃仍有衰减过程，不代表所有动态重力都被消除。

FIR 的群延迟为 31 个样本，即 124 ms。去直流部分另有频率相关相位，不能把整个级联称为严格线性相位。名义频率分析假定输入均匀250 Hz；目前实物已有短间隔记录，后续需补采样时序，不能用 PL 计算速度证明真实数据频谱准确。

## 数值格式和溢出规则

| 数据／寄存器 | 位宽及含义 |
|---|---|
| 原始输入 | signed 16 位，-32768～32767，单位为原始加速度计数 |
| 基线 `baseline_q` | signed 32 位，16 个小数位；实数值为寄存器整数除以 65536 |
| 基线差 `error_q` | signed 33 位，先扩展符号再作 `(x<<16)-baseline_q` |
| 去直流输出 | signed 17 位，整数计数，理论范围 -65535～65535 |
| FIR 系数 | signed 18 位，16 个小数位；系数实数值为整数除以 65536 |
| FIR 乘积 | signed 35 位，完整保存 17×18 位有符号乘积 |
| FIR 累加器 | signed 41 位，乘积扩展符号后累加，不逐抽头截位 |
| FIR 输出 | 默认 signed 18 位，整数计数；末尾统一舍入和饱和 |

基线更新使用 `baseline_q + (error_q >>> 5)`，负数移位按向负无穷取整；先作33位运算再存回32位。由于更新是向输入目标的收敛更新，合法16位输入下基线不会越出32位范围。不能直接用16位整数均值更新，否则小变化可能过早停止更新。

去直流差和 FIR 最终结果均采用四舍五入，恰好半单位时远离零。用绝对值加半单位后右移，再恢复符号；负数不能直接加正半单位右移。最后按输出位宽夹紧，不允许回绕。绝对值、加偏置和比较使用充分扩展的临时位宽，禁止隐式无符号扩展。

当前量化系数和为65536，保持单位低通直流增益；对称且中心系数修正和，不移动其它抽头。系数绝对值和为117520，故合法去直流输入的累加绝对值界限为：

```text
65535 × 117520 = 7701673200
输出绝对值上界约为 117518.21 计数
```

41位累加和默认18位输出均覆盖此界限。正常默认系数下预计不触发18位饱和，仍保留保护；用较窄 `OUT_WIDTH` 的专用 TB 参数验证正负饱和分支。不能为了复用16位UART而在 FIR 内无提示截断。

## dc_remove 接口与时序

文件：`rtl/dc_remove.v`。端口为 `clk`、同步高有效 `rst`、`sample_valid_i`、`restart_i`、`data_i`（signed16），以及 `data_o`（signed17）、`valid_o`。该模块可每拍接收一个有效样本，外层负责接纳和限速。

- 仅 `sample_valid_i=1` 的上升沿更新状态；无有效样本时基线和输出数据保持，`valid_o=0`。
- 第一个有效样本，或有效样本同拍 `restart_i=1`：基线装载 `x<<16`，输出0，仍产生有效事件。
- 后续有效样本：对旧基线求差、输出舍入值，同时更新基线，两个操作不得误用新基线。
- 接收沿之后 `valid_o` 与该样本结果同时有效；下级时序逻辑在下一上升沿使用它。
- `rst` 优先，清除初始化标志及有效事件；`restart_i` 只与有效样本共同解释，不在空闲时反复清零。

核心寄存器为32位基线、一位已初始化标志、17位输出与有效寄存器，不设重复状态机。

## fir_lp_serial 接口、存储与状态机

文件：`rtl/fir_lp_serial.v`。输入 `clk/rst`、`data_i`（signed17）、`valid_i`、随输入握手的 `restart_i`；输出 `ready_o`、`data_o`（默认signed18）、`valid_o`、`saturated_o`、`history_full_o`。`valid_i && ready_o` 才接纳样本。忙时允许发送端保持请求，需保证数据稳定；外层事件接口与此握手接口不可混淆。

主要寄存器：63×17位环形历史、6位写/读地址、6位抽头索引、7位有效历史计数、17位样本寄存器、18位系数寄存器、35位乘积、41位累加器和输出寄存器。地址显式0～62回绕，不能直接利用6位自然溢出。

系数从 `fir_lp_63_q16.mem` 读取。运行脚本将核查SHA256并复制到独立工作目录；综合脚本也应显式提供该文件。缺文件、X/Z 系数或数量不符应使检查失败，不能用全零系数继续报告通过。

| 状态 | 行为 |
|---|---|
| IDLE | ready=1；握手时写入新样本，锁存历史头，清累加器，抽头从0开始 |
| LOAD | 读取当前历史样本与系数到寄存器；尚无效的历史抽头直接取0 |
| MUL | 计算并寄存完整35位乘积 |
| ACC | 将乘积符号扩展到41位后累加；还有抽头则返回LOAD，否则进入ROUND |
| ROUND | 对最终累加器统一舍入/饱和，结果及 valid 同拍提交，返回IDLE |

接受沿记为t=0，tap0在t=1/2/3依次LOAD/MUL/ACC，tap62在t=187/188/189处理，t=190提交结果；下一输入最早在t=191接受。此周期合同已由两个仿真器的TB逐拍核对。

复位或握手时 restart 只清有效历史计数和地址，不必逐个清历史RAM；计算阶段对无效历史屏蔽为0，防止未初始化数据泄漏。restart 样本自身仍作为新序列第一个样本。第63个样本开始 `history_full_o=1`，前62个结果是定义明确的补零瞬态。此标志仅表示FIR历史完整，不能称为直流估计已完全稳定。

每轴一套串行乘加器，三轴并行运行，便于学习和独立测试。DSP是否按预期映射、寄存器/存储资源及时序以实际综合为准，隔离实现已测得3个DSP、2282 LUT、3901 FF；内部建立/保持裕量分别9.198ns/0.117ns，端口边界待最终集成，具体警告见实现报告。

## vibration_filter 事件接口及调度

文件：`rtl/vibration_filter.v`。输入 `clk/rst`、一拍 `frame_valid_i`、`seq_i[7:0]`、signed16三轴；输出 `ready_o`、`busy_o`、一拍 `filtered_valid_o`、对应SEQ、signed18三轴、`history_full_o`、`saturated_o`、一拍 `overrun_o`、一拍 `stream_restart_o`，以及32位接纳/丢弃/重启计数。

这里是与包解析器一致的一拍事件接口。`frame_valid_i && ready_o` 接纳；忙时来的事件丢弃、产生overrun并计数，不覆盖当前输入，也不更新基线或历史。丢弃后标记下次需重新建立状态。上游没有反压，不能假设解析器会等待ready；重复保持valid将被解释成重复事件。

调度状态为 `IDLE`、`DC`、`FIR`、`WAIT`：

| 相对输入接纳沿 | 动作 |
|---|---|
| t=0 | IDLE接纳并锁存三轴、SEQ及是否重启，离开ready状态 |
| t=1 | DC向三个去直流实例提交锁存数据，得到寄存结果 |
| t=2 | FIR向三个空闲 FIR 实例握手提交去直流结果，转WAIT |
| t=192 | 三个FIR结果在各自输出端有效 |
| t=193 | 外层同时锁存三轴及SEQ，发filtered_valid，回IDLE |
| t=194 | 最早可以接纳下一个事件 |

默认处理延迟193拍，即3.86us，最短接纳间隔194拍，即3.88us，远小于4ms。该延迟不包含UART整包接收和输出发送时间，也不等于124ms信号群延迟。三轴有效若未同拍，应作为TB失败，不能混合不同样本。

### 序号、断流与恢复

- 首个合法输入建立序号与基线；正常模256连续，包括FF→00，不重启。
- 跳号、重复或前次内部丢弃后，下次接纳样本以 restart 方式开始新历史；该样本仍得到定义为0的首次去直流输出。输出携带原SEQ，不重编号。
- 默认断流阈值 `GAP_TIMEOUT_CLKS=600000`，50MHz下为12ms。计数饱和；一次连续断流只标记一次，历史完整标志失效。下一样本接纳时重启，不在没有输入时生成伪样本或周期性推进FIR。
- 明确边界：从上次接纳沿t起，t+600000到来的样本也按达到阈值处理，不把等于阈值算连续。实现用旧计数值检查，TB覆盖阈值前/等于/之后。
- 配置阈值必须大于外层处理延迟，避免忙时超时与有效结果竞争；非法参数应报告错误。即便达到阈值，尚未接纳新样本也不恢复历史完整标志。
- 坏校验、坏停止位或截断帧不会产生合法包有效事件，不能推进数值状态。下一完整包若SEQ不连续或已断流，会自动重启。
- 全局同步复位可在任何计算状态打断，丢弃在途结果，清有效标志、历史有效计数及诊断计数；后续合法输入可恢复。

这些规则避免把明显缺包后的相邻寄存器值当成连续250Hz信号，但不能恢复传感器内部漏掉的样本，也不能消除3ms/4ms级采样抖动。
