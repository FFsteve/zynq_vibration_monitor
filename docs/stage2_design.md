# 第二阶段：数据包解析与 UART 发送设计

用户已接受第一阶段、暂缓上板，并授权继续第二阶段。本阶段沿用既有 10 字节草案的布局，不改变包头、校验算法或字节序；补齐下述接收规则，作为当前实现约定。只进行 PL 逻辑及仿真，不创建板级顶层、STM32 固件、PS 或烧录流程。

## 数据包与接收规则

```text
A5 5A SEQ XH XL YH YL ZH ZL CHK
CHK = SEQ XOR XH XOR XL XOR YH XOR YL XOR ZH XOR ZL
```

三轴为 16 位补码，高字节先传；串口字节内部仍低位先传。完整且校验成功的包才更新序号及三轴数据，`frame_valid_o` 仅一拍。坏包、超时和 UART 错误不覆盖最近的合法输出。

序号按模 256 连续。复位后的首个合法包建立基准；跳号或重复触发 `seq_error_o`，但仍接收该合法包。超时或 UART 错误保留最近合法序号，便于诊断断流后的不连续。

解析器采用 80 位滑动窗口与 4 位填充计数。每次收到字节后检查最近十字节；校验失败仍保留窗口并继续滑动，不因载荷含 A5 5A 而提前重启。成功接收后清空窗口，开始搜索下一个非重叠包。

字节超时默认 `BYTE_TIMEOUT_CLKS=100_000`，50 MHz 下为 2 ms。最后一次字节接收沿记为 n，之后到 n+100000 仍无新字节则清空窗口并输出一拍 `timeout_o`。若新字节恰好在边界到达，也先丢弃旧窗口，再把该字节作为新窗口的首字节。因此可拼接字节的间隔必须严格小于阈值。UART 错误优先于同拍字节和超时。

成功包后窗口为空，正常包间空闲不产生超时。只有缓存非空时才计时；垃圾字节引起的非空窗口也可能超时。`checksum_error_o` 表示“包头匹配的十字节候选校验失败”，不能直接解释为真实损坏包数量。

XOR 不能检出所有多位错误或交换，未转义包头可能偶然匹配；本实现不承诺在任意恶意或随机字节流中绝无伪包。指定损坏、插入、删除和截断用例必须能恢复到后续合法包。

## packet_parser 接口与寄存器

| 接口 | 方向 | 职责 |
|---|---|---|
| clk、rst | 输入 | 系统时钟、高有效同步复位 |
| byte_i[7:0]、byte_valid_i | 输入 | UART 已验证字节及一拍有效事件 |
| byte_error_i | 输入 | UART 停止位错误；清空当前窗口，同拍字节丢弃 |
| seq_o[7:0] | 输出 | 最近合法序号 |
| x_o、y_o、z_o | 输出 | 最近合法三轴，均声明为 signed [15:0] |
| frame_valid_o | 输出 | 合法包提交事件，一拍 |
| checksum_error_o | 输出 | 候选校验失败事件，一拍 |
| timeout_o | 输出 | 非空窗口超时清除事件，一拍 |
| seq_error_o | 输出 | 合法包序号不连续事件，与 frame_valid_o 同拍 |

内部保存 80 位窗口、4 位填充计数、默认 17 位空闲计数器，以及一位首包标志。状态由填充计数表达，不另设重复状态机：空窗口搜索、部分窗口收集、满窗口逐字节滑动。无反压接口，支持每拍一个输入字节；下游须接受每个整包有效事件。

## uart_tx 接口与状态机

默认 CLK_HZ=50_000_000、BAUD=115_200，每位 434 拍。接口为 clk、同步 rst、data_i[7:0]、valid_i，以及 ready_o、tx_o、busy_o、done_o。

仅在上升沿 `valid_i && ready_o && !rst` 时接收请求并锁存字节。忙时修改 data_i 不影响当前帧；忙时仅打一拍 valid 不会缓存请求。需要等待的发送端应保持 valid 和数据，直到握手成功。

| 状态 | 行为 |
|---|---|
| IDLE | tx_o=1，等待握手 |
| START | tx_o=0，保持完整一位 |
| DATA | D0 到 D7，每位保持完整 BIT_CLKS 拍 |
| STOP | tx_o=1，保持完整一位，结束时 done_o 一拍 |

ready 在空闲时及停止位的最后一个周期可用，允许同一沿完成上一帧并接收下一帧，保持恰好一个停止位的连续发送。此时 done_o 与下一帧起始可同时发生，busy_o 保持高。复位优先，立即在复位沿将输出置高并终止未完成帧，不输出完成事件。

若接受请求的沿为 t=0：START 为 [0,N)，D0 为 [N,2N)，D7 为 [8N,9N)，STOP 为 [9N,10N)，done 在 10N。默认完整字节为 4340 拍，86.8 us。内部为 8 位锁存、3 位位索引、2 位状态与默认 9 位倒计数，不生成新时钟。

## 自检与验收

- 解析器：正常连续包、三轴正负极值、大端、载荷含包头、坏包头/校验、插入/删除、各处截断、超时前/边界/后、UART 错误优先级、复位、序号回绕/跳号/重复、单周期事件与输出保持。
- TX：独立按时间解码串行输出，遍历 256 字节，检查逐位保持、完整停止位、连续握手、忙时请求、输入修改、各阶段复位及恢复；测试默认和奇数分频参数。
- 模块链路：在纯仿真 TB 中连接 TX→RX→解析器，验证合法包、损坏、超时、UART 错误和后续恢复。该链路不是板级顶层，也不构成板测证据。
- 两套仿真器分别执行同一组用例，脚本检查当前结果文件与退出码；不把第一阶段历史结果当作本阶段执行结果。
