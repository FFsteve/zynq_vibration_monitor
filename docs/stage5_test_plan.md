## isqrt_u36

- 使用 `math.isqrt` 提供期望，覆盖0、1、所有关键平方前/本身/后、2³⁴/2³⁵附近、2³⁶-1与固定种子随机；输入文件不能用32位integer读取36位被开方数。
- 每个结果检查根、余数与 `r²<=n<(r+1)²`，最大余数不能丢失高位。
- 严格18拍输出、19拍最短接纳间隔；忙时输入变化/单拍请求不污染当前快照，保持请求只在ready时接纳一次。
- 迭代开始、中间、末次之前复位，取消旧valid；随后正常输入恢复。

## window_features

- 三轴零、不同常量、正负极值、交替极值、首项冲激、末项冲激、整周期正弦和独立随机；逐窗对照Python精确整数结果。
- 重点覆盖 `abs(-131072)=131072`、全负最小值平方、128项最大累加值、除法截断、RMS整数下界；不得在18位有符号绝对值或32位乘法处先溢出。
- 验证最后一项同时进入能量和峰值。首末冲激应得到相同均方/峰值，输出前不能提前清和。
- 窗长1、2、4、128、1024；首窗必须恰好收满才输出，窗口无重叠，空闲不制造样本。
- 时序：非末项接受间隔最短3拍；末项到结果22拍，下一次最早23拍；三个RMS同拍提交。
- 多次SEQ回绕正常；跳号/重复废弃旧部分窗，当前样本成为新窗首项。window_id跨质量清理继续递增，只有全局rst清零。
- MUL、ACC、ROOT_START、ROOT_WAIT和发布边界的clear/rst覆盖；clear与输入/完成同拍优先，无旧结果外泄。
- 忙时新事件触发overrun并取消部分/在途窗，计数准确、长clear不反复计数；随后完整窗口恢复。正常第四阶段194拍间隔不得过载。

## threshold_alarm

- ON²之前/等于/之后、OFF²之前/等于/之后，默认2000/1500且两窗确认；特别验证比较平方而非被截断的错误RMS。
- 连续高值置位、连续低值解除、死区保持状态但中断计数；间隔的超限不能拼成连续确认。
- 三轴独立高低组合及综合OR，只有对应轴改变；首窗valid、持续状态和事件脉冲分别检查。
- 窗口确认数1、2及较大值，计数边界不提前/不晚一窗。最大ON=131072须以足够位宽平方，不能32位溢出。
- 无新feature时所有报警计数保持；clear/rst优先于同拍feature，valid失效，质量清理不伪造一次正常解除事件。
- 非法窗长/阈值顺序/越界/确认数0必须被拒绝，结果文件不能残留旧PASS。

## feature_monitor_core

- 真正从UART位流输入，通过既有第四阶段后产生统计，不直接用TB伪造内部filtered_valid冒充串口集成。
- 用Python独立生成原始三轴、去直流/FIR和完整窗口期望，覆盖从冷启动到历史有效，再经过足够多的低/高/低窗口，验证报警置位与解除。
- 原始十字节回传仍逐字节独立解码一致；统计字段、首末SEQ、window_id和报警对齐，避免新统计配旧报警。
- 第四阶段首62个历史不完整样本不计入窗口；首结果和后续512ms名义更新间隔单独核对。
- 坏校验、停止位、各处截断、序号缺口和断流后取消部分窗口、报警状态失效；恢复后必须重新凑满，不保留旧确认计数。
- 增加默认50MHz/115200参数通道；加速仿真明确标注压缩比例，不当作实物采样时序。
- 另以独立辅助通道定向注入历史不足、饱和、过载、重启及发布边界故障，只验证质量门控，不冒充真实UART或滤波算术结果。
- 随机/控制向量逐字段匹配，RTL开方结果必须与math.isqrt完全一致，MS及峰值不得仅按浮点近似验收。

## 执行和阶段完成标准

已按获批方案编写四个RTL和四个自检，配套 `sim/run_stage5.ps1`。每项在ModelSim和XSim分别执行，检查退出码、当前结果文件、错误数和完成标志，保存诊断波形；两套仿真器都使用独立期望，不相互生成参考。

再对实际RTL导出执行独立检查，对新增或集成计算逻辑作隔离综合、资源和内部时序检查。保持20ns目标，不用无依据的端口预算代表板级签核；如涉及原有UART，保留既有异步同步链语义。警告和未约束父级接口须单列。

实现期间按已授权流程自行运行这些检查，无需再次询问常规仿真。复现命令和波形操作见[测试指南](stage5_test_guide.md)，未实际运行的实物项继续标记未验证。上板、校准、真实阈值和真实采样稳定性留到最终阶段。
