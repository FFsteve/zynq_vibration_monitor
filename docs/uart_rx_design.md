# 第一阶段：UART 接收器设计

用户于 2026-10-27 批准第一阶段。本阶段仅实现 UART 字节接收，不包括包解析、TX、板级顶层、外部复位引脚或 STM32 固件。10 字节协议仍为草案。复现步骤和实际证据见 `stage1_test_guide.md` 与 `../report/stage1_validation.md`。

## 接口

`rtl/uart_rx.v` 使用可综合的 Verilog-2001，全部逻辑由 clk 上升沿驱动。

| 名称 | 方向或默认值 | 约定 |
|---|---|---|
| CLK_HZ | 参数，50_000_000 | 输入时钟频率，单位 Hz |
| BAUD | 参数，115_200 | 标称波特率 |
| clk | 输入 | 系统时钟 |
| rst | 输入 | 高有效同步复位，至少覆盖一个时钟上升沿 |
| rx_i | 输入 | 异步、空闲高、非反相的 8N1 串行数据，字节内低位先发 |
| data_o[7:0] | 输出 | 最近一次合法字节；复位为零；坏帧时保持 |
| valid_o | 输出 | 合法字节提交时拉高一拍，与新数据同时生效 |
| framing_error_o | 输出 | 停止位采样为低时拉高一拍，不提交字节 |
| busy_o | 输出 | START/DATA/STOP 为高，IDLE/WAIT_HIGH 为低 |

本模块没有反压接口，下游必须接收每个有效脉冲。busy=0 不一定表示已准备好接收，因为 WAIT_HIGH 也输出 0。复位或坏停止位后，同步输入必须连续保持一整位高电平才能重新使能。恢复测试提供两位高电平以留出余量；不保证在坏停止位后没有恢复空闲时立即接收首个字节。

CLK_HZ、BAUD 必须为正，每位至少四个时钟。使用前必须施加时钟同步复位，未来顶层负责上电复位；该逻辑接口不代表指定了物理复位脚。

## 寄存器与同步

| 寄存器 | 默认位宽 | 用途 |
|---|---:|---|
| rx_meta、rx_sync | 各 1 | 两级同步，带 ASYNC_REG 和 SHREG_EXTRACT 属性 |
| rx_prev | 1 | 保存同步输入的前值，检测下降沿 |
| state | 3 | 五状态状态机 |
| baud_cnt | 9 | 采样倒计数；WAIT_HIGH 中统计连续高电平 |
| bit_idx | 3 | 数据位索引 0..7 |
| shift_reg | 8 | 尚未提交的接收字节 |
| 数据与事件输出寄存器 | 8/1/1 | 保存已提交数据，产生单周期事件 |

只有 rx_meta 直接采样 rx_i，状态机使用 rx_sync。数字仿真无法证明真实亚稳态行为或平均无故障时间。最终板级层次尚不存在，因此候选 XDC 不猜测层次化伪路径命令。后续仅对异步端口到第一级寄存器的路径设置例外，保留同步级之间的时序检查，并检查实现后的跨时钟域结构。

## 状态机

| 数值与状态 | 行为和转换 |
|---|---|
| 0 WAIT_HIGH | 统计 BIT_CLKS 次连续高电平；低电平清零；完成后进入 IDLE |
| 1 IDLE | rx_prev=1 且 rx_sync=0 时，装载 HALF_CLKS-1 并进入 START |
| 2 START | 等待 HALF_CLKS 拍；低电平确认起始并进入 DATA，高电平按假起始返回 IDLE |
| 3 DATA | 每 BIT_CLKS 拍采样到 shift_reg[bit_idx]，D7 后进入 STOP |
| 4 STOP | 等待 BIT_CLKS 拍；高则提交字节、输出 valid 并进入 IDLE，低则输出错误并进入 WAIT_HIGH |

复位优先于所有状态；默认分支返回 WAIT_HIGH。假起始位不产生有效或错误事件。有效起始后若持续低电平，只报告一次停止位错误，然后等待恢复，不重复报错。

## 计数器与周期时序

```text
BIT_CLKS  = round(CLK_HZ / BAUD) = 434
HALF_CLKS = floor(BIT_CLKS / 2)  = 217
内部等效波特率 = 50,000,000 / 434 = 115207.3733 baud
分频误差 = +0.0064004%
```

将检测到同步下降沿的时钟上升沿定义为 t=0。装载 N-1，在计数为零时采样，恰好等待 N 个后续时钟周期。全部逻辑保持在 50 MHz 域，不额外生成逻辑分频时钟。

| 事件 | 相对 t=0 的时钟周期数 |
|---|---:|
| 起始位确认 | 217 |
| D0 | 651 |
| D1 | 1085 |
| D2 | 1519 |
| D3 | 1953 |
| D4 | 2387 |
| D5 | 2821 |
| D6 | 3255 |
| D7 | 3689 |
| 停止位检查及有效/错误事件 | 4123 |

物理输入下降沿到 t=0 还有同步与检测延迟，本 RTL 标称为两到三个时钟周期。TB 的精确周期检查以同步检测点为基准，不以物理输入沿为基准。

合法停止位中心确认后立即返回 IDLE，支持仅一个停止位的连续字节。奇数分频时半位延迟向下取整；每位 33 拍的测试同时检查了计数器位宽变化。

## 限制

本设计使用单点中心采样。起始确认点已恢复为高的脉冲会被拒绝，但不能拒绝所有短脉冲或噪声波形。数据中心毛刺可改变字节而不产生停止位错误。停止位只在中心检查，不持续监测完整高电平位宽；TB 明确验证这些限制。

发送端 +/-2% 波特率偏差与有界逐位抖动的验证，只适用于本次实际测试的两组配置，不能推广到全部参数或噪声来源。整包校验、超时和重新同步由未来包解析器负责。
